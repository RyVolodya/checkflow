# CheckFlow v0.10.0

## UI redesign
- Reworked the complete interface into a cleaner modern CRM-style visual system.
- New white light theme and near-black dark theme.
- Refined navigation, headers, forms, panels, cards, tables, Kanban columns and modals.
- Work cards now use compact CRM styling with status accent rails and cleaner metadata.
- Responsive behavior remains available for desktop, tablet and mobile layouts.

## Efficiency
- Replaced the bar chart with a responsive SVG line chart.
- Added combined trend for all Employees + Managers.
- Added individual Employee / Manager selection for privileged users.
- Employee accounts continue to see only their own data.
- Administrator accounts are excluded from team efficiency aggregation.
- Modern KPI cards and CRM-style performance table.
- Completed and overdue trends are shown as separate lines.

## Compatibility
- Existing application workflows, tasks, checklists, templates, groups, history, Telegram integration and Kanban behavior are preserved.
- No database schema migration is required for this release.
